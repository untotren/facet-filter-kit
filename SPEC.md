Build a dependency-free, framework-free ES module `facetFilter` plus one stylesheet. Input: an array of items `{id: string, title: string, tags: string[], fields: Record<string, number|string>}` and a facet schema `[{key, type: 'tags'|'range'|'enum', label, options?}]`. Output: (1) `createFilter(items, schema)` returning a pure state object with `apply(state) -> string[]` of matching ids in stable input order; (2) `toQuery(state) -> string` and `fromQuery(string) -> state` that round-trip exactly for any valid state; (3) `mount(el, filter, {onChange})` that renders accessible controls (fieldset/legend per facet, checkbox groups, min/max number inputs for ranges, live-region result count, visible focus, full keyboard operation, aria-pressed/aria-checked state), and a no-results panel with a 'clear all' control. No network calls, no analytics, no globals except the module export, no build step required (plain ESM, ES2020). Tests: Node test runner, property-based URL round-trip over randomly generated states (seeded), keyboard navigation via jsdom, empty-result rendering, stable sort, 250 generated sample items across six fictional categories as the fixture (generated by a script in the repo, committed). Include demo/index.html that loads the module and fixture.
